# 储能舱电池热失控蔓延仿真系统

纯前端实现：TypeScript + WebGPU（WGSL 计算着色器）+ IndexedDB，零运行时依赖。
面向储能电站消防评审，回答三个核心问题：

1. 一颗电芯热失控会不会把整簇带着烧起来？
2. 模组里加不加气凝胶隔热垫，差异有多大？
3. 全氟己酮（FK-5-1-12）几秒喷、喷了能不能压住？

## 启动

```bash
npm install
npm run dev          # 开发，自动开浏览器（Chrome/Edge 116+，需硬件加速）
npm run build        # 类型检查 + 生产构建
npm run test:verify  # 物理校验测试（Node 环境，无需浏览器）
npm run test:perf    # 1.2 万电芯规模与性能测试
```

浏览器不支持 WebGPU 时自动回退到 CPU 参照求解器（Float64），公式完全同源。

## 物理模型

### 热网络（每颗电芯一个节点）

- 电芯间导热：分层材料热阻串联 `R = Σ(δ/λ)`，再按接触面积换算电导 `G = A/R`；
  铝排作为并联导电路径单独计入。
- 每颗电芯与 4 个面内邻居（±X 串联、±Y 并联）、模组外壳节点、液冷板节点相连。
- 模组外壳为独立热容节点，外壳间、外壳与舱内空气换热。
- 显式欧拉积分，自适应步长：`dt ≤ 0.25·C/ΣG`（Fourier 稳定性准则），超出自动切小。

### 产热与状态机

每颗电芯四态：正常 → 自产热（T≥T1，分段线性功率表）→ 失控喷发中（T≥T2 或外部强制）
→ 喷发结束。喷发期总能量按 `ventDuration` 均布释放，并以观测峰值温度做一阶弛豫热库钳温
（工程等效，模拟燃烧/喷焰对芯体的外部加热；峰值温度是可配置输入项）。

### 液冷

按每簇支路流量算 `m·cp`，沿管路模组位置线性温升；泵故障支路在设定时刻 `mdot=0`，
该簇电芯与冷板停止换热。WGSL 中用 u32 定点毫瓦原子加归算每簇换热功率。

### 探测与喷放

分区（每簇一区）模型：失控电芯喷发物按喷发时长线性释放，气体/烟感按
`累积量/分区体积 ≥ 阈值` 判报警；温感按分区最高温判报警。喷放时刻 = 首次报警 + 延时，
喷放后按设定的等效降温速率 K/s 作用到全部电芯。

## 物理正确性校验（`npm run test:verify`）

**三颗电芯串排手算算例**：cell1 设为恒温热库，cell2/cell3 为两节点 RC 网络，
用矩阵指数求解析解（特征值 `λ = a·(-3±√5)/2`），CPU 显式积分解与之对比：

- 首次蔓延（cell2 达 T2）时间误差 **≤5%**（实测约 0.06%）
- 到达 T2 前温度轨迹偏差 <8K

同套测试还覆盖：异常参数数量级拦截、832 电芯端到端蔓延、探测器报警与喷放联动、
停泵簇温升高于正常簇。

### 数量级错误拦截

测试数据（`src/model/seed.ts`）的 40 尺两簇舱里故意塞了三颗问题电芯：
`#17` 导热倍率 ×0.001、`#120` ×200、`#333` 比热 ×0.05。
校验器直接点名报 error 并阻止仿真，不会"算出一舱炸"。

## 性能

1.2 万电芯（10 簇 × 12 模组 × 100 芯）、2 小时物理时间：
全局最小稳定步长约 34s，限 dt≤2s 时全程仅 3600 步；CPU 外推墙钟约 4s，
独立显卡 GPU 更快，3 分钟目标有数量级裕度。GPU 侧采用分块提交（0.5s 物理时间一块）
+ 周期回读，主线程每块让出事件循环，画面不卡死。

## 目录结构

```
src/
  model/      领域类型、默认参数、拓扑构建（热阻/电导）、参数校验、测试种子数据
  physics/    物理公式单一事实源、CPU 内核、引擎编排、探测器模型、报告、三电芯解析校验
  gpu/        WGSL 计算着色器 + WebGPU 求解器（打包缓冲，≤8 storage/阶段）
  render/     WGSL 实例化渲染（温度色标、喷发锥、剖切、射线拾取、蔓延连线）
  store/      轻量 observable store + IndexedDB 持久化
  pages/      六个页面
  test/       Node 侧校验与性能测试
```

CPU 内核（`thermalCore.ts`）与 WGSL（`compute.wgsl`）按同一组公式逐式对应，
任何物理改动必须两边同步，并重新跑 `test:verify`。

## 建模口径与边界

- 集总参数热网络，电芯内部温度均匀；不模拟电芯内部隔膜级反应动力学。
- 热库钳温、喷放降温速率、探测器分区浓度均为工程标定输入，应按厂家试验报告校准。
- 评审报告已注明：详细设计需结合全尺寸热失控试验复核，本系统用于方案阶段横向对比与机理展示。
