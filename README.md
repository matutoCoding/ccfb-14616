# 储能舱热失控蔓延仿真系统

纯前端 TypeScript + WebGPU/WGSL 应用,在浏览器里对集装箱储能舱做电芯级热失控蔓延仿真,
用于消防评审场景下对比隔热垫、喷放延时等方案。无后端、无运行时第三方依赖,方案与结果存 IndexedDB。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建到 dist/
npm run test:phys  # 三电芯手算物理校验(5% 限值)
```

浏览器需支持 WebGPU(Chrome/Edge 113+);不支持时自动回退到 CPU 参考求解器与 Canvas2D 渲染。

## 六个页面

1. **舱体布置** — 20/40 尺集装箱、簇数/模组数/电芯阵列,改动自动重排;液冷流量、进液温度、停泵支路;俯视图
2. **电芯模组** — LFP/NCM 电芯全套热物性;气凝胶垫/铝排/导热胶厚度与导热系数;外壳、冷板;个别电芯参数覆盖
3. **触发场景** — 过充/针刺/加热板,最多两处同时触发,可在模组网格上点选电芯
4. **蔓延仿真** — WebGPU 计算着色器求解,上万电芯实例化渲染、温度上色、喷发方向、按簇剖切、舱体半透明、时间轴回放、失控序列与蔓延连线
5. **探测喷放** — 可燃气/烟感/温感与全氟己酮喷嘴布置,分区气体模型估算报警时刻与喷放时刻
6. **评审报告** — 4 组方案(基准/无隔热垫/加厚垫/喷放延时)自动对比,导出 JSON / CSV / Markdown

## 物理模型

- 每颗电芯一个节点,相邻电芯、模组外壳、液冷板按接触面积与材料串联热阻连接,热阻在 CPU 侧预算
- 自产热按温度分段线性(每化学体系一张 W/kg 表);热失控喷发为三角形功率曲线
- 喷发后火焰平台温度反馈 + 相邻面灰体辐射(ε·F·A·σ·ΔT⁴),驱动跨电芯蔓延
- 液冷沿支路串行计算沿程温升,支持停泵工况(停滞工质自然对流)
- 显式欧拉积分,步长由 `dt ≤ 0.4·min(C/ΣG)` 稳定判据自动确定
- WGSL 计算着色器(`src/gpu/thermal.wgsl`)与 TS 参考求解器(`src/physics/referenceSolver.ts`)逐方程同构

## 物理可信度校验

`test/phys.test.ts` 用三组算例卡 5% 限值:

- **A 线性 RC 闭式解**:恒温壁 + 两自由度 RC 链,矩阵特征值解析解对比数值解(误差 <0.2%)
- **B 完整蔓延**:独立标量循环重写整套热平衡,对比参考求解器的首/次蔓延时间(误差 ~0.01%)
- **C 步长收敛**:步长减半后蔓延时间变化 <2%

## 参数防呆

`src/physics/validation.ts` 在求解前拦截数量级/单位错误:导热系数、比热、放热量等超出
工程区间或偏离缺省值 5 倍以上即报错。演示舱(`createDemoProject`)故意注入 3 颗错误参数电芯
(#12 接触导热 18、#300 比热 11000、#500 放热量 340000),校验器必须全部报出,避免"算出一舱炸"。

## 性能

12000 颗电芯、2 小时物理时间、9000 积分步、1800 帧回放快照:
- WebGPU 计算着色器约 6 秒
- CPU 参考求解器约 50 秒(回退路径)

均满足 3 分钟以内要求,且求解在分块提交间让出主线程,页面不卡死。
